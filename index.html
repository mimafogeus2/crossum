How to play

  1. Fill every blank tile with an operator so each row and column is a true equation.
  2. Tiles where lines cross are shared — one symbol has to work both ways.
  3. Usual math order: × ÷ before + −. Division must come out whole.
  4. Later levels add ^ (power, first of all) and % (remainder).

Keyboard: + - * / = ^ %, arrows to move, ⌫ to clear.
